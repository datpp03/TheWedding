# Ý Tưởng Nâng Cấp

Thư mục này là nguồn chính cho ý tưởng nâng cấp. Mỗi ý tưởng nằm trong một file riêng để dễ đưa vào roadmap, chuyển thành prompt, hoặc đánh dấu đã triển khai.

## Quy Ước

- Dùng `y-tuong-nang-cap/_TEMPLATE.md` khi thêm ý tưởng mới.
- Không lặp ý tưởng đã có; nếu gần giống, cập nhật file hiện tại.
- Đây là backlog gợi ý, không phải cam kết roadmap.
- Khi một prompt phát hiện ý tưởng mới, tạo file vào đúng nhóm và cập nhật mục lục này nếu cần.
