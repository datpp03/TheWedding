# [~] Tên Việc Cần Làm

- Mức độ: Khẩn cấp / Ưu tiên / Có thể đợi / Quyết định sản phẩm / Đã xử lý.
- Nguồn: prompt hoặc docs tạo ra việc này.
- Owner: Người dùng / Agent / Cả hai.
- Trạng thái: `[ ]` chưa làm / `[~]` đang chờ / `[x]` đã làm.

## Mục Tiêu

Mô tả kết quả cần đạt, không chỉ ghi tên việc.

## Chuẩn Bị

- Tài khoản, credential, domain/DNS, env, dữ liệu test, dịch vụ trả phí hoặc quyết định cần có.

## Các Bước Thực Hiện

1. Bước cụ thể thứ nhất.
2. Bước cụ thể thứ hai.
3. Bước cụ thể thứ ba.

## Nơi Cấu Hình / Kiểm Tra

- File env, dashboard dịch vụ, URL app, trang admin, command hoặc log cần xem.

## Xác Nhận Hoàn Tất

- Kết quả mong đợi, smoke test, màn hình/API/log phải pass.

## Docs Liên Quan

- `docs/...`

## Ghi Chú Cho Prompt Sau

- Nếu còn blocker, ghi rõ file/prompt kế tiếp cần xử lý và mức ưu tiên.
